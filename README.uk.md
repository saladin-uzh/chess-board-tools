# Chess.com Confirm Move Hotkeys

[English version](README.md)

Мінімальне Chrome/Chromium-розширення Manifest V3 для керування вікном
підтвердження ходу на Chess.com за допомогою налаштовуваних гарячих клавіш,
із додатковим напівпрозорим туманом війни для ботів та аналізу.

## Локальне встановлення

Розширення не розповсюджується через Chrome Web Store. Його потрібно
встановити як unpacked extension із локальної копії цього репозиторію.

### 1. Отримайте файли розширення

Виберіть один із варіантів:

- Клонуйте репозиторій:

  ```bash
  git clone https://github.com/saladin-uzh/chess-confirm-move-hotkeys.git
  ```

- Або виберіть **Code → Download ZIP** на GitHub і розпакуйте завантажений
  архів. Не намагайтеся завантажити ZIP-файл безпосередньо в Chrome.

### 2. Завантажте unpacked extension

1. Відкрийте `chrome://extensions` у Chrome або Chromium-браузері.
2. Увімкніть **Developer mode**.
3. Натисніть **Load unpacked**.
4. Виберіть розпаковану папку `chess-confirm-move-hotkeys`, яка містить
   `manifest.json`.
5. Перезавантажте вкладки Chess.com, які вже були відкриті.

Після отримання оновлень через Git або повторного завантаження натисніть
**Reload** на картці розширення в `chrome://extensions`, а потім перезавантажте
вкладку Chess.com.

## Гарячі клавіші та налаштування

- `Space` — підтвердити хід.
- `Escape` — скасувати хід.

Натисніть іконку розширення на панелі браузера, щоб відкрити popup. Popup
показує короткий опис розширення і дозволяє змінити клавіші підтвердження та
скасування. Зміни зберігаються автоматично й застосовуються до відкритих
вкладок Chess.com без перезавантаження сторінки.

Літерні клавіші відповідають літері в активній розкладці незалежно від її
фізичного розташування. Гарячі клавіші стають активними після завантаження
налаштувань. Елементи popup вимкнені під час завантаження та збереження.

Розширення обробляє клавішу лише тоді, коли відповідна видима й активна кнопка
підтвердження або скасування присутня на сторінці. Воно ігнорує події у формах,
текстових полях і редагованих елементах, а також комбінації з
клавішами-модифікаторами.

## Підтримувані сторінки

Content script запускається лише на таких URL:

- `https://www.chess.com/play/*`
- `https://www.chess.com/game/*`
- `https://www.chess.com/analysis/game/*`

## Напівпрозорий туман війни

У popup увімкніть **Semi-transparent Fog of War**, оберіть непрозорість
(20–80%, початково 55%) та перспективу Auto, White або Black. Початково туман
вимкнений. Auto використовує колір гравця в партії проти бота; для окремої
дошки аналізу потрібно явно обрати сторону. Поворот дошки повертає маску,
зберігаючи обрану перспективу.

Підтримуються `/play/computer`, окремий `/analysis` та завершені партії на
`/analysis/game/live/*`, `/analysis/game/daily/*` і `/analysis/game/computer/*`.
Туман недоступний у партіях проти людей, класах, інших варіантах шахів,
за неповного стану та на непідтримуваних сторінках. Використання проти людей
не входить до цього випуску відповідно до
[політики чесної гри Chess.com](https://www.chess.com/legal/fair-play).

Без туману залишаються клітини ваших фігур та їхніх можливих переміщень.
Далекобійні фігури зупиняються біля перешкоди, коні перестрибують її, а пішаки
бачать порожні ходи вперед і доступні взяття, а не всі діагоналі атаки.
Рокіровка враховує справжні права й вільний шлях; en passant — поточне поле
FEN і чергу ходу. Шах, зв'язки та атаки на короля не обмежують цю видимість.
Відкрита клітина не означає, що хід туди дозволений у звичайних шахах.

Вибір своєї фігури додає контур її видимості, зберігаючи загальну маску.
Накладання пропускає кліки, перетягування й керування дошкою. Туман повертається
на клітини, які більше не видно; пам'яті досліджених зон немає. За непевного
стану або анімації маска прибирається. Popup повідомляє про недоступність.
Після оновлення перезавантажте розширення та сторінку за інструкцією вище.

Адаптер читає доступний API дошки Chess.com. Якщо цей API зміниться, туман
стане недоступним: права рокіровки та en passant не виводяться з розташування
фігур.

## Усунення проблем

- Перезавантажте вкладку Chess.com після встановлення або оновлення розширення.
- Переконайтеся, що підтвердження ходу ввімкнене в налаштуваннях Chess.com.
- Натисніть іконку розширення і переконайтеся, що popup показує очікувані
  налаштування гарячих клавіш.
- Відкрийте консоль сторінки та знайдіть повідомлення
  `[Chess.com Confirm Move Hotkeys] Initialized.`
- Перевірте, що поточний URL відповідає одному з підтримуваних шаблонів.

## Безпека та приватність

Розширення використовує дозвіл `storage` лише для збереження налаштувань
гарячих клавіш і туману. Воно не виконує зовнішніх мережевих запитів, не збирає та не
передає дані. Воно запускається лише на перелічених URL Chess.com.

Параметри відображення туману зберігаються окремо в `chrome.storage.local`.
Знімки позиції використовуються в пам'яті для малювання маски; розширення
не зберігає позиції, історію ходів чи ідентифікатори облікових записів і партій.

## Тести

З Node.js 18 або новішим виконайте `node --test tests/*.test.cjs`.
Тести використовують підставні DOM і Chrome storage API та не потребують
облікового запису Chess.com.
Вони перевіряють гарячі клавіші, правила видимості, повноту стану, підтримуваний
контекст, конкурентне збереження налаштувань та життєвий цикл накладання.
Перевірки у справжньому браузері записуються окремо в
[контрольному списку реалізації](docs/fog-of-war-implementation.md).
