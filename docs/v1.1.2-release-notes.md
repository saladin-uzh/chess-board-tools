# v1.1.2 — Pawn fog, human keyboard controls, and store preparation

- Fix pawn fog visibility to follow capture diagonals rather than forward movement (PR #13).
- Restore keyboard coordinate controls for human games opened at `/game/<numeric-id>` (PR #14).
- Enable keyboard input in native daily-game analysis and clear buffered input when switching between analysis and playing (PR #15).
- Use Chess Board Tools consistently in the manifest, toolbar title, and popup.
- Include system light/dark popup appearance from PR #12 (issue #11), preserving native controls and settings behavior.
- Prepare English/Ukrainian store descriptions, review instructions, support/privacy pages, store artwork, and a macOS packaging handoff.
- Add deterministic runtime-only ZIP packaging with SHA-256, provenance, and signed-tag verification for final builds.

No new permissions, dependencies, storage migrations, or telemetry were added. Chrome Sync applies to shortcut preferences; fog and board helpers stay local. Safari setting synchronization is not promised.

This version is a local release candidate until its commit and tag are manually signed. Support/privacy pages are deployed; all five public pages returned HTTP 200 on 2026-10-10. Store enrollment, real cross-device Sync, signed Safari packaging, and store submission remain separate gates; see `manual-release-steps.uk.md` and `store-preparation-validation.md`.
