# v1.0.0 release validation

Based on `57663de`, which already includes semi-transparent Fog of War.
This release narrows confirmation/cancellation choices, implements standalone
Control release, pauses hotkeys while an input has focus, makes Auto fall back
to the bottom side, and compacts the popup. Board keyboard control and thinking
ticks are excluded and will be reviewed separately.

Validation on 2026-10-09:

- Node regression tests cover defaults, removed values, per-action allowed
  choices, conflicting pairs, both Control keys, chords, input focus, shadow
  editable focus, and existing storage/load/save behavior.
- Fog tests cover fallback White/Black, known player color precedence, manual
  perspective stability, and existing complete-state/context boundaries.
- Shared fix code was exercised in an unpacked extension in Chrome for Testing
  154: standalone analysis Auto activated without a side prompt; flipping
  changed the fallback from White to Black. The action popup fit its contents
  without a scrollbar or clipping, including the larger feature-preview UI.
- Existing fog live-browser evidence remains in `fog-of-war-implementation.md`.
- Real confirmation-prompt behavior and Safari runtime remain unverified in
  this release. The current Safari extension folder was not changed or reloaded.

No positions, game history, or account identifiers are added to persisted data.
