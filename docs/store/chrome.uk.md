# Chrome Web Store — українська

Назва: Chess Board Tools

Короткий опис: Керування клавіатурою, клавіші підтвердження, звукові сигнали ходу й туман війни для підтримуваних дошок Chess.com.

## Повний опис

Користуйтеся клавіатурою на підтримуваних дошках Chess.com і налаштовуйте допоміжні функції.

• Підтверджуйте чи скасовуйте очікуваний хід налаштовуваними клавішами (типово Space/Escape). Дія виконується лише за наявності видимої активної кнопки Chess.com.
• Увімкніть керування дошкою з клавіатури й вводьте координати послідовно: b, 2, потім b, 3. Для перетворення пішака використовуйте q/r/b/n. Дії призупиняються у полях введення та інтерактивних елементах.
• Увімкніть тихий сигнал кожні 10 секунд свого ходу. Звук потребує попередньої взаємодії з вкладкою, мовчить у прихованих вкладках і вимкнений в аналізі.
• Тренуйтеся з напівпрозорим туманом війни проти ботів, у самостійному аналізі та оглядах завершених стандартних партій. Оберіть прозорість 20–80% і перспективу Auto, White або Black. Туман недоступний в активних партіях із людьми, варіантах та непідтримуваних чи неповних станах дошки. Пішаки відкривають діагоналі взяття замість клітин ходів уперед. Видимість не гарантує легальності ходу.
• Popup налаштувань автоматично використовує світлу чи темну тему браузера/системи.

Допоміжні функції спочатку вимкнені. Chess.com перевіряє ходи та зберігає власний процес підтвердження. Розширення не оцінює позиції рушієм, не рекомендує ходи й не грає автоматично. Клавіатурні кліки використовують звичайний pointer-шлях сайту; розширення не приховує синтетичні події й не обходить перевірки.

Приватність: код розширення не робить зовнішніх запитів, не збирає телеметрію та не зберігає позиції чи історію партій. Параметри підтвердження/скасування використовують Chrome Sync, якщо його ввімкнено. Параметри туману й допоміжних функцій залишаються в локальному сховищі браузера. Поточний стан дошки обробляється лише в пам’яті.

Безкоштовно. Без реклами, підписок чи покупок. Незалежний проєкт, не пов’язаний із Chess.com і не схвалений ним.

## Поля dashboard

Єдине призначення: Керування дошкою Chess.com користувачем із клавіатури та додаткові візуальні/звукові засоби для підтримуваних дошок.

Обґрунтування storage: Збереження обраних клавіш підтвердження/скасування через chrome.storage.sync та параметрів туману, клавіатури й сигналів через chrome.storage.local. Позиції, історія ходів та ідентифікатори облікових записів/партій не зберігаються.

Доступ до сайту: Content scripts працюють лише на перелічених маршрутах play, game та analysis домену https://www.chess.com для визначення доступних кнопок, взаємодії з дошкою за командою користувача та відображення допоміжних функцій. Доступ до інших сайтів не потрібен.

Віддалений код: Відсутній; усі JavaScript і стилі входять до пакета.

Декларації приватності: Розробник не збирає, не передає, не продає й не поширює дані користувачів. Стан дошки обробляється локально й тимчасово. Chrome Sync може обробляти параметри клавіш; не позначайте всі параметри як виключно локальні. Підтвердження dashboard заповнюються відповідно до цих фактів і фінального пакета.
