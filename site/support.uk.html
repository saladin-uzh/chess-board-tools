Підтримка — Chess Board Tools

Повідомте про проблему в GitHub Issues. Додайте версію розширення, браузера й операційної системи, назву функції, очікувану поведінку та кроки відтворення на одноразовій дошці аналізу. Не публікуйте дані облікового запису чи приватні посилання на партії.

Безпечна перевірка

Відкрийте аналіз Chess.com з одноразовою позицією. Не тестуйте в активній партії з людиною. У popup увімкніть Keyboard board control; введіть латинські b, 2, потім b, 3. Дії клавіатури призупиняються, коли фокус у полі введення чи інтерактивному елементі.

Встановлення й дозволи

Chrome: дозвольте роботу розширення на Chess.com і перезавантажте відкриті вкладки після встановлення. Для наявного тимчасового встановлення Safari увімкніть Chess Board Tools у Safari Settings → Extensions, дозвольте доступ до Chess.com і відкрийте нову тестову вкладку після Reload розширення. Версію для macOS App Store не опубліковано.

Поширені питання

  • Підтвердження потребує видимої активної кнопки Chess.com. Скасування використовує Cancel або очищує всю чергу premoves на активній ігровій дошці, зокрема під час ходу суперника й із вимкненим Keyboard board control.
  • Звукові сигнали мають режими Auto, Increment і фіксовані інтервали 2–30 секунд та гучність 0–100%. Auto потребує відомого початкового часу; 0% вимикає звук. В аналізі, задачах і прихованих вкладках сигналів немає. У партії проти бота один раз взаємодійте з вкладкою для розблокування аудіо.
  • Piece Vision Overlay спочатку вимкнений. Він підтримує стандартних ботів, аналіз, завершені огляди, аналіз поточних Daily-партій та задачі Rated/Daily/Learning. Активна гра проти людей, Rush/Battle, варіанти й неповні стани його вимикають. Клітинки, невидимі обом сторонам, мають темніший туман із діагональними смугами.
  • Клавіші використовують Chrome Sync, якщо його ввімкнено. Туман і допоміжні функції локальні. Safari не синхронізує параметри розширення.
  • Після оновлення unpacked extension перезавантажте розширення й відкрийте нову вкладку Chess.com. Перезавантаження тимчасового Safari extension може потребувати нової вкладки.
