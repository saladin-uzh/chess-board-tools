Privacy — Chess Board Tools

Effective date: 9 October 2026.

What the extension processes

The extension reads the current supported Chess.com board and interface in memory to provide keyboard controls, sound cues, and fog. It does not persist positions, move history, account identifiers, or game identifiers. Board access does not give the developer access to your account.

Saved settings

The storage permission saves preferences only. Confirmation and cancellation shortcuts use chrome.storage.sync. With Chrome Sync enabled, Chrome can synchronize them between signed-in Chrome browsers. With Sync disabled they remain local; offline changes can synchronize when connectivity returns.

Fog settings (enabled, opacity, perspective) and board helpers (keyboard control and turn ticks) use separate chrome.storage.local keys and do not synchronize. Safari implements the sync storage API but does not synchronize these settings between devices.

No developer collection

The extension code makes no external network requests, sends no telemetry, and saves no game history. It contains no advertising or analytics SDKs and sells or shares no personal data. It provides no engine evaluation or move recommendations.

Other services

Chess.com and your browser have their own privacy policies. Chrome Sync is a browser service, not a developer server. This documentation site is hosted by GitHub Pages; hosting infrastructure may process technical request information under GitHub’s privacy statement. These pages contain no analytics, cookies set by our code, or third-party scripts. GitHub Issues submissions are public: do not include account details, private game links, or secrets.

Control and support

Disable features in the popup, remove website access in browser settings, or uninstall the extension. Synced settings are governed by Chrome’s Sync controls; uninstalling is not a promise of deletion from every synchronized device. For privacy questions use GitHub Issues without posting personal data.
