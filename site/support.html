Support — Chess Board Tools

Report a problem on GitHub Issues. Include extension version, browser version, operating system, feature, expected behavior, and reproduction steps on a disposable analysis board. Do not post personal account data or private game links.

Safe test board

Use Chess.com analysis and a disposable position. Do not test in an active human game. Enable Keyboard board control in the popup; type Latin b, 2, then b, 3. Keyboard actions pause in focused inputs and interactive controls.

Installation and permissions

Chrome: allow the extension on its supported Chess.com pages. Safari: open the containing app, follow the enablement instructions, and enable Chess Board Tools in Safari Settings → Extensions. Allow access to Chess.com and reload the test tab. The App Store build targets macOS 27; it is not released yet.

Common questions

  • Confirm/cancel shortcuts work only when Chess.com shows a visible enabled confirmation/cancellation button. Check the site’s move-confirmation setting.
  • Turn ticks are deliberately silent in analysis and hidden tabs. In a disposable bot game, enable the option and interact once to unlock audio.
  • Fog starts disabled. It works on supported standard bot boards, analysis, and completed game reviews; active human games and unsupported/incomplete positions disable it.
  • Shortcut keys use Chrome Sync when enabled. Fog and board helper settings stay local. Safari does not synchronize extension settings.
  • After updating an unpacked extension, reload it and reopen the Chess.com tab. Temporary Safari extension reloads can require a fresh tab.
