Що обробляє розширення

Розширення читає поточну підтримувану дошку та інтерфейс Chess.com у пам’яті для керування клавіатурою, звукових сигналів і Piece Vision Overlay. Воно не зберігає позиції, історію ходів, ідентифікатори облікового запису чи партії. Доступ до дошки не надає розробнику доступу до вашого облікового запису.

Приховування гравців візуально маскує імена, аватари й рейтинги в панелях біля дошки. Нативні дані залишаються на сторінці для відновлення; чат, списки, профілі та експорт не анонімізуються.

Збережені параметри

Дозвіл storage використовується лише для параметрів. Гарячі клавіші, туман, нумерація стрілок, приховування гравців і допоміжні функції використовують chrome.storage.sync. Коли Chrome Sync увімкнено, Chrome може синхронізувати їх між браузерами Chrome із вашим обліковим записом. Коли Sync вимкнено, вони залишаються локальними; офлайн-зміни можуть синхронізуватися після відновлення з’єднання.

Наявні локальні параметри допоміжних функцій переносяться в Sync, якщо синхронізоване значення відсутнє. Наявні синхронізовані значення мають пріоритет. Після успішного перенесення локальна копія видаляється; у разі помилки вона залишається для повторної спроби. Safari підтримує API sync storage, але не синхронізує ці параметри між пристроями.

Позиція й розмір плаваючої панелі налаштувань зберігаються локально. Відкритий стан залишається в пам’яті поточної вкладки й не синхронізується.

Розробник не збирає дані

Код розширення не робить зовнішніх мережевих запитів, не надсилає телеметрію та не зберігає історію партій. Немає реклами чи аналітичних SDK; персональні дані не продаються й не передаються. Розширення не оцінює позиції рушієм і не рекомендує ходи.

Інші сервіси

Chess.com і браузер мають власні політики приватності. Chrome Sync — сервіс браузера, а не сервер розробника. Сайт документації розміщено на GitHub Pages; інфраструктура хостингу може обробляти технічні дані запитів відповідно до політики GitHub. Сторінки не містять аналітики, cookie, встановлених нашим кодом, чи сторонніх скриптів. Звернення в GitHub Issues публічні: не додавайте дані облікових записів, приватні посилання на партії чи секрети.

Керування та підтримка

Вимкніть функції в popup, заберіть доступ до сайту в налаштуваннях браузера або видаліть розширення. Синхронізованими параметрами керує Chrome Sync; видалення розширення не гарантує видалення з усіх синхронізованих пристроїв. Запитання щодо приватності можна залишити в GitHub Issues без персональних даних.
