Що обробляє розширення

Розширення читає поточну підтримувану дошку та інтерфейс Chess.com у пам’яті для керування клавіатурою, звукових сигналів і Piece Vision Overlay. Воно не зберігає позиції, історію ходів, ідентифікатори облікового запису чи партії. Доступ до дошки не надає розробнику доступу до вашого облікового запису.

Збережені параметри

Дозвіл storage використовується лише для параметрів. Клавіші підтвердження та скасування використовують chrome.storage.sync. Коли Chrome Sync увімкнено, Chrome може синхронізувати їх між браузерами Chrome із вашим обліковим записом. Коли Sync вимкнено, вони залишаються локальними; офлайн-зміни можуть синхронізуватися після відновлення з’єднання.

Параметри туману (увімкнення, прозорість, перспектива) та допоміжних функцій (клавіатура, звукові сигнали, їхня частота й гучність) використовують окремі ключі chrome.storage.local й не синхронізуються. Safari підтримує API sync storage, але не синхронізує ці параметри між пристроями.

Позиція й розмір плаваючої панелі налаштувань зберігаються локально. Відкритий стан залишається в пам’яті поточної вкладки й не синхронізується.

Розробник не збирає дані

Розширення не надсилає телеметрію та не зберігає історію партій. У його коді немає рекламних чи аналітичних SDK; персональні дані не продаються. Розширення не оцінює позиції рушієм і не рекомендує ходи.

Опційна турнірна панель

Відкриття турнірної панелі завантажує другу штатну сторінку Chess.com із поточною сесією браузера. Ця сторінка робить звичайні запити сайту, зокрема до сторонніх ресурсів, і надсилає повідомлення, коли ви відправляєте їх через штатний чат. Розширення не записує вміст чату чи ідентифікатори турнірів у постійне сховище, не читає облікові дані й не передає їх на сервер розробника. URL, розмір і відкритий стан панелі залишаються в пам’яті вкладки. Закриття прибирає додаткову сторінку.

Інші сервіси

Chess.com і браузер мають власні політики приватності. Chrome Sync — сервіс браузера, а не сервер розробника. Сайт документації розміщено на GitHub Pages; інфраструктура хостингу може обробляти технічні дані запитів відповідно до політики GitHub. Сторінки не містять аналітики, cookie, встановлених нашим кодом, чи сторонніх скриптів. Звернення в GitHub Issues публічні: не додавайте дані облікових записів, приватні посилання на партії чи секрети.

Керування та підтримка

Вимкніть функції в popup, заберіть доступ до сайту в налаштуваннях браузера або видаліть розширення. Синхронізованими параметрами керує Chrome Sync; видалення розширення не гарантує видалення з усіх синхронізованих пристроїв. Запитання щодо приватності можна залишити в GitHub Issues без персональних даних.
