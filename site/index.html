Chess Board Tools

Keyboard controls and optional board helpers for Chess.com

Configure move confirmation shortcuts, enter squares with the keyboard, and use optional turn sound cues. Practice with semi-transparent fog against bots, in analysis, and in completed standard-game reviews.

Independent project. Not affiliated with or endorsed by Chess.com. Free, without advertising, purchases, or subscriptions.

The Chrome Web Store and macOS App Store editions are being prepared. Store installation is not available yet.
